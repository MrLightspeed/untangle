# Code of conduct

Treat contributors with respect. Discuss code and evidence, welcome good-faith
questions, and keep feedback specific and constructive.

Harassment, threats, discriminatory abuse, doxxing, spam, and repeated unwanted
contact are unacceptable. Do not publish another person's private information.

The repository owner moderates project spaces. They may edit or remove content,
close discussions, or restrict participation. Responses depend on the severity
and repetition of the conduct.

Use GitHub's **Report content** feature for abusive content. Do not repeat
private information in a public issue. For a non-sensitive conduct concern, open
a help issue that identifies the public discussion.
