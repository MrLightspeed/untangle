# Support

For an installation or usage question, use the
[help issue form](https://github.com/MrLightspeed/untangle/issues/new/choose).
Include the Untangle release or commit, agent and version, operating system,
Python version, and installation method. If you used the Skills CLI, include its
version; for `npx`, include Node.js and npm versions. Share the command that
failed and the smallest sanitized example that shows the problem. Remove
credentials and private source.

Search existing issues first. Add details to an open issue when it covers the
same problem. Community answers are welcome. Replies and implementation depend
on maintainer capacity.

You can help by improving the documentation, sharing a sanitized example,
testing a proposed correction, or sharing the project.

To support Untangle financially, visit the
[GitHub Sponsors page](https://github.com/sponsors/MrLightspeed). It offers
one-time and monthly contributions. Sponsorship does not include a service,
review, response time, or implementation commitment.
